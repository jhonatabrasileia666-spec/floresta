# FLORESTA — Survival Dark Fantasy

Jogo 3D de sobrevivência em primeira pessoa, com construção, forja, alquimia, criaturas e combate.

## Publicação da V265
**Status:** repositório preparado; aguardando envio dos arquivos completos da V265.

A estrutura usa `index.html` para escolher PC/Mobile e `PC.html`, `Mobile.html` e `Jogo.html` como entradas. Os diretórios `assets/` e `modulos/` são indispensáveis. Não publique apenas o HTML ou o ZIP.

Para publicar no GitHub Pages, após enviar os arquivos, abra **Settings → Pages → Build and deployment → Source: GitHub Actions**. O workflow em `.github/workflows/deploy-pages.yml` publicará os arquivos da branch `main`.

Endereço esperado depois da ativação: https://jhonatabrasileia666-spec.github.io/floresta/
